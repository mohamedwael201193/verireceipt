# Stock chart and name resolution reuse

24 November 2026. Extends the bounded quote cache to stock-price and Yahoo name discovery. No new provider, auth key, retry, host/header/IP rotation or new probe. Both equity handlers use the same chart URL including interval=1d&range=1d, ticker key in Yahoo uppercase dash spelling, exact body and acquisition timestamp. Both chart fetches and search share the same module-level Retry-After cooldown. An invalid success is refused, never a stale pass or cache replacement. Every caller revalidates a deduplicated in-flight body before use.

Search cache keys are separate from quotes and normalize only case and whitespace, matching the requested search URL normalization. Cache is bounded128 total entries across namespaces. Same5minute fresh / strictly below15minute maximum acquisition age.429 or5xx can reuse only a prior validated exact body. Search resolution is rerun against the newly retrieved SEC index, including ambiguity/refusal checks. No prior or expired observation still refuses. Search provenance records original acquisition and age independently of chart acquisition and SEC evidence collection. Either stale component sets stale verdict and confidence0.5; a stale resolution with a fresh price cannot be labelled verified. Exact raw bodies remain in receipt evidence. Stock receipt fetched_at is the original quote acquisition time; checked_at is current processing time. Numeric slots alone cannot carry staleness, so JSON/text/evidence disclosures are retained.

Offline tests replay existing real chart/SEC captures, synthetic name alias responses and synthetic429/5xx/invalid transitions. Synthetic alias is explicitly not a claimed live Yahoo search capture. Cold cache or prolonged outage beyond15minutes remains unavailable. Existing parser scope/error semantics are retained; stock keeps its pre-existing exchange-time validation, while financial-data retains its7day exchange-time ceiling. No deploy or manifest changes.
