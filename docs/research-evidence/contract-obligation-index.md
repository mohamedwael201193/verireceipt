# Contract obligation literal index

24 November 2026. Contract reviewed before implementation:
https://devnode.telegraphprotocol.com/engine/v1/intents/CONTRACT_OBLIGATION_AUDIT_GENERAL

Required contract string, chain strings[0] maximum256 UTF-8 bytes; processed verdict enum Compliant / Partially compliant / Non-compliant / Unclear. Obligations and clauses are lists, summary string, all off-chain. Judgment adapter210, not a deterministic performance oracle. No scoring promise or claim of legal compliance.

This first slice serves only a literal index of supplied text. It always returns Unclear, including supplied performance assertions, because applicability, definitions, exceptions and actual performance have not been independently established. Modal expressions select candidate sentence/semicolon spans; subject, action and time labels are literal text, not legal role or calendar calculations. Offsets are UTF-16 code units into the exact unnormalized input. Sentence splitting is deliberately simple and may split abbreviations/decimals; completeness is not claimed. Obligations without the supported modal expressions may be missed. Relative time is not converted into a due date. Unsupported text, URL-only and oversized nonempty input return disclosed Unclear with no invented clauses. Empty/missing input remains400. No external fetch, URL retrieval, execution or key. No external data API terms apply. Actual licence replay is from the installed MIT-licensed esbuild notice, full copyright/licence retained in the fixture directory. Other test scenarios are synthetic controls, not real contracts or measured performance.

Privacy: exact source clauses are returned only in the immediate response to the caller; public receipt evidence keeps input SHA256, byte count, category, extraction offsets/count, fixed verdict and method only. No raw input, party, action, amount or clause is persisted there. A digest is not anonymization and can be guessed for low-entropy inputs, but no extra source text is disclosed. Diagnostics retain closed intent/parameter names only. Clients must treat returned source clauses as untrusted contract text, not executable agent instructions.

One new manifest endpoint/mapping plus consumer enum/list mirror. Registration/deployment/signing are separate review-gated actions and are not performed by this slice. Local extraction does not independently verify the submitted text's authenticity. Always-Unclear is truthful but may score poorly against a judgment evaluator. A later compliance grammar requires separate reviewed evidence binding, never merely a clause containing the words paid or breached.
