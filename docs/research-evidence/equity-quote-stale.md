24 November2026. No alternate source, new source approval, hostname rotation or live quote probe. Existing Yahoo source only. A process-wide Yahoo cooldown covers chart and search for every asset, minimum60seconds, extended by Retry-After seconds or HTTP date. No automatic retry. Same-ticker in-flight loads deduplicate. Quote cache bounded128entries, keyed by SEC-resolved ticker, validated symbol/USD/EQUITY/positive finite price and exchange timestamp no more than7days old.7days accommodates non-trading days; exchange time is always named, not claimed current.

Exact successful quote bytes and acquisition time cache5minutes fresh. Only HTTP429/cooldown or5xx may reuse a retained quote below15minute acquisition age. Invalid200/mismatched/expired/no prior quote refuses. Cache has no persistence, so deployment cannot seed a previously blocked process. SEC data still fetched independently; SEC failure does not become a stale pass. Derived cap may combine current SEC shares with the cached price, explicitly named a mixed-age derivation. No price is estimated/advanced. Output stale flag/reason, age, original quote time, exchange time, stale verdict and reduced confidence distinguish fallback. Receipt contains original chart bytes and separate derivation/acquisition times.

This cannot fix a cold cache or an outage lasting beyond15minutes. Refusal remains the honest result there. No alternate keyless quote source is activated; any alternate needs terms review and parent report before use.
