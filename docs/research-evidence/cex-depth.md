# Explicit CEX spot depth

Terms checked2026-11-23: https://www.gemini.com/legal/api-agreement allows keyless public API reads at120/minute but does not clearly grant redistribution in the fetched text; OEMS redistribution is treated separately. https://www.bitstamp.net/api/ directs commercial users to a signed data licence, while allowing incorporation and redistribution under its commercial-use section. This testnet use proceeds under the owner's separately recorded terms-risk acceptance, not a claim of commercial permission. No challenge,403 or access-control workaround is allowed. No order-book cache, only the minimal receipt evidence required for verifying the returned computation. Shared process cap30starts/minute is below both services' published limits.

The public scoring registrations inspected for the leading book sources declare generic/query mappings with no declared pool/chain fields, not reusable query examples. Their actual public documentation specifies a pair in the book path. This endpoint therefore uses an explicit selector: chain=gemini or chain=bitstamp, pool=BTC/USD or ETH/USD (compact BTCUSD/ETHUSD also accepted). A DEX chain is never silently reinterpreted as a CEX. No DEX pool name or address is routed here.

Computation: total bid plus ask USD notional within plus/minus2% of the best-bid/ask midpoint. Fixed8decimal arithmetic for prices and quantities, rounded to cents once at output. USD quote pairs only, no assumed stablecoin peg. Source timestamp must be within30seconds, book uncrossed and strictly sorted, both tails must span the full band. This is posted CEX depth, not DEX reserve TVL or guaranteed executable size. Venue/pair identity is bound by the fixed endpoint path, since book bodies do not echo a symbol.

Real complete BTC/USD books were fetched successfully from both official endpoints; unmodified bodies are fixtures. No production keys or account access are used. YAML unchanged. No source fallback between venues and no averaging. The source's raw body, original timestamp, retrieval time, band and bid/ask subtotals are receipted.
